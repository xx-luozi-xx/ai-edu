# 工作流

### 1. 需求分析

&emsp;&emsp;面向实验需求和用户操作逻辑，分析软件/应用需求，具体需要获取：**用户需要什么操作**, **最终需要收集什么数据**等。(注意，用户包括科研者/软件管理员/一般用户等一切可能操作软件的人员)
&emsp;&emsp;进一步，确定客户端操作逻辑(操作功能)和形式(网页/app)

### 2. 架构设计
&emsp;&emsp;基于需求分析，设计账户/权限管理，数据结构维护，前后端等总架构。

### 3. 试用原型和迭代
&emsp;&emsp;搭建小规模最小可用版本，进行初步试用，收集改进反馈，以一定的周期进行迭代。

### 4. 大规模部署和维护
&emsp;&emsp;正式投入使用的版本，要求能长时稳定运行。
